FlyLight Downloader

Download FlyLight driver-line imagery directly from the Janelia S3 bucket (janelia-flylight-imagery) and the HTTP CDN (flimg.janelia.org). The line type is detected automatically: R-lines (Gen1 GAL4) and SS-lines (Split-GAL4) come from S3, VT lines from the CDN.

Quick start

  1. Enter one or more driver lines and press Enter after each one so they appear as removable chips, e.g. R10A06, VT037867, and SS00731.
  2. Pick an output directory (defaults to your saved default).
  3. Click Download Images. Progress streams below; files appear in Output Files when the run finishes.

Preview tools

ActionBehavior
Search LinesFind driver lines matching a pattern (e.g. R10A0, VT037, SS01). Click a result chip to add it to the line list.
List FilesShow the exact files the current filters would download, without downloading. Click a file name to open its URL.

File filters

ParameterDefaultMeaning
Formatspng, jpgFile formats: png, jpg, h5j (3D stacks), lsm (raw confocal), mp4 (videos), json (metadata). VT lines primarily have jpg/mp4.
Image Typesmip, cdmMIP / CDM projections, aligned stacks, metadata, translation videos.
RegionBrainRestrict to brain imagery, VNC, or keep all regions.
CollectionsGAL4/LEXA, SplitGAL4 Collection categories searched in priority order; missing lines fall back to MCFO and then RawImages.

Download options

ParameterDefaultMeaning
Simple ModeonDownload only representative files: 20x + multichannel for Split-GAL4 (excluding image1/image2 duplicates), total for GAL4/LexA. A small fallback keeps at least a few files when nothing matches.
Max Files / Line6Cap per line (applied after filtering). Blank = no limit.
Max Workers4Parallel download threads.
Flat StructureonSave files directly instead of preserving the S3 key structure.
Timestamp FolderonCreate a flylight-downloads_..._{timestamp} output folder so re-runs never overwrite.
Image SummarypdfGenerate a PDF / PPTX contact sheet of the downloaded images.

Notes

  • Downloads need internet access to s3.amazonaws.com and flimg.janelia.org; no API token is required (public data).
  • Large files (h5j stacks, lsm raw data) can be hundreds of MB — the log streams the total size before downloading.
  • Backend: src/flylight_downloader.py (same engine used by the NeuronBridge Find Lines image download).
Exported run guide: every successful run also writes _UserGuide_please_read_me.html into the run folder — a self-contained explanation of every output file, every table column, and any warnings recorded for the run. Format (html / txt / markdown / disabled) is set in Settings → Default Settings → Run Guide Format.
