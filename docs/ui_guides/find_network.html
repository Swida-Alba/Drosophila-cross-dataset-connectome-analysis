Network

Build the mutual direct-connection network among the queried neurons — equivalent to Direct Connections with source == target == the query set. Runs on the FindAllPath backend (enrichment, hemisphere-aware analysis, network + heatmap visualizations without Sankey).

Limited scope: the network contains only direct connections whose BOTH endpoints are in the queried set — intermediate neurons are never involved. For a more complete network that also involves intermediate neurons, use the Complete Paths tab with Find Reciprocal Connections enabled.

Quick start

  1. Pick the dataset and, if needed, an Output Directory (it inherits your saved default otherwise).
  2. Add the Query Neurons (e.g. aMe12, PPL101, or an uploaded list).
  3. Pick the Threshold Basis (Synapse count or Connection ratio) and set the threshold — ratio mode reads Min Connection Ratio (%); Combine Thresholds (Any one / Both AND) decides whether both gates apply.
  4. Optionally define Custom Groups (label-mapper panel) or set a Custom Group Name / Custom Target Name / Save Folder Name for the run.
  5. Click Find Network.

Score formulas

Connection scores are computed on the thresholded graph: on the Synapse basis, edges with weight ≥ Min Synapse Count; on the Connection-ratio basis, edges with ratio ≥ Min Connection Ratio (the synapse count floors to 1 — the ratio is the threshold). Ratios use the global total incoming weight, so the denominator reflects the whole dataset:

connection_ratiow_ij / Σ_k w_kj over D_t (edge weight ÷ total input to the post neuron)0–1

Pair report and type-level refill

Every network run also produces the per-pair explorer report the pathfinding tools generate: the run writes a 1-hop path-compatible table (*_allpaths_type.csv), and the same post-run hook builds path_report.html + paths_pair_breakdown/ from it — per-pair breakdown with coverage hovers and a Refill tab.

The type-level refill is always produced: every network run writes the full-scope refill records (the type_level_refill/ mirror) — every emitted chain re-valued at the synapse ≥ 1 full connection scope. Ratio-basis runs additionally get the complete-at-asked records; synapse-basis runs get refill-asked records when a budget bit, which a network never has — so for networks the refill is full-scope only.

  path_report.html, paths_pair_breakdown/  # per-pair explorer report
  type_level_refill/               # (ratio-mode runs; complete-at-asked)
