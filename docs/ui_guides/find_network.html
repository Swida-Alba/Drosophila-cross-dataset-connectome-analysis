Network

Build the mutual direct-connection network among the queried neurons — equivalent to Direct Connections with source == target == the query set. Runs on the FindAllPath backend (enrichment, hemisphere-aware analysis, network + heatmap visualizations without Sankey).

Limited scope: the network contains only direct connections whose BOTH endpoints are in the queried set — intermediate neurons are never involved. For a more complete network that also involves intermediate neurons, use the Find Path tab with Find Reciprocal Connections enabled.

Quick start

  1. Add the Query Neurons (e.g. aMe12, PPL101, or an uploaded list).
  2. Set Min Synapse Count (plus ratio/probability thresholds if needed).
  3. Click Find Network.

Score formulas

Connection scores are computed on the thresholded graph D_t (edges with weight ≥ Min Synapse Count). Ratios use the global total incoming weight, so the denominator reflects the whole dataset:

ScoreFormulaRange
connection_ratiow_ij / Σ_k w_kj over D_t (edge weight ÷ total input to the post neuron)0–1
traversal_probabilitymin(1.0, connection_ratio / 0.3) (30% input = maximal)0–1
block_probability1 − traversal_probability0–1

Full derivations live in Score Calculation Guide.

Output

The folder name uses the dataset abbreviation (MCNS = male-cns, FAFB = flywire FAFB, ...) and a sanitized query name (e.g. aMe.* → aMe):

{output_dir}/find-network_MCNS_aMe_w3r0p0_20260815_142745/
  parameters.txt, all_attributes.json
  data_details/
    neurons.csv                     # all queried neurons
    connection_type.csv             # type-level mutual connections
    parameters.csv
    connection_info_bodyId.csv      # (when Skip BodyId is off)
    connection_custom_groups.csv    # (when a custom grouping is used)

  visualization/
    Network_*.html, Heatmap_*.html  # NO Sankey
    visualization_data/             # *_data_connections.csv,

                                    # network_edges_input.csv
