Morphology

The Morphology tab holds the skeleton-based similarity workflows, switched with the buttons at the top of the panel:

  • Find Similar — query-vs-all morphological similarity search within one dataset (Vector (spatial) or NBLAST method). Find Similar guide
  • Comparison — N×N morphology comparison of already-identified neurons, within one dataset or across datasets (the intra-dataset run chooses its matrix row as a type, an individual neuron, or a custom group; bodyId-level matrices, heatmaps, report). Comparison guide
Cross-dataset vs intra-dataset: Find Similar is intra-dataset. The Comparison sub-tab switches to cross-dataset morphology when two or more datasets are selected: it scores cross-dataset pairs with the shared raw-basis vector engine (per-dataset caches; each pair scores in the target dataset's render space) and writes one merged report — see the Cross-Dataset guide.

Which sub-tab do I need?

GoalSub-tab
Find neurons with similar skeleton shape to a queryFind Similar
Compare shapes of 2+ known neurons (same dataset)Comparison (one dataset)
Compare neuron shapes across two or more datasets (homologs)Comparison (2+ datasets → cross-dataset mode)

Output

Find Similar saves each run in its own timestamped folder (similar-morphology_{dataset}_{query}_{timestamp}) under the selected output directory and writes the exported run guide (_UserGuide_please_read_me.html) next to the results. See the Find Similar guide for the full file tree and scoring details.
