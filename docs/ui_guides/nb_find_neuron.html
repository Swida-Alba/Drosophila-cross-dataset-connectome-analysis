Find EM Neurons

Find EM neurons whose morphology matches a GAL4 / Split-GAL4 driver line.

Quick start

  1. Enter one or more Driver Line Names (e.g. VT037867, R10A06, SS00731).
  2. Click Find EM Neurons.

Inputs & examples

Line nameType
VT037867VT GAL4 line
R10A06Gen1 GAL4 line
SS00731Split-GAL4 line

Multiple names can be comma/newline separated; each line is processed independently.

Parameters

ParameterDefaultMeaning
Algorithmcdscds, pppm, or both
Top N Matches Per Line50Ranked matches retained per line; this count is applied before the score cutoff
Score Cutoff30000Threshold for score-based annotations; top-N result files retain lower-scoring matches
Visualize Top NeuronsonRender top matches in 3D
Visualize BytypeGroup visualizations by type or bodyId
Sort Bymax_scoremax_score or type_avg_score
PDF SummaryonIndividual profile PDF/PPTX
Result visualizations default to Skeleton Mode = line for speed. For high-quality morphology, open Visualization → Skeleton, or select tube with the fine method and 95% simplification.

Output detail

Full (default) keeps every exported file. Compact drops the bodyId-level match tables (all_neurons.csv, {line}_neurons.csv, by_dataset/*_neurons.csv) once the per-dataset type summaries are written — every removal is audited in the run's cleanup_audit.json. Type summaries, the type-mapped table, the distribution plot, and 3D renders always stay. The NeuronBridge match cache is off by default (Settings → NeuronBridge Match Cache re-enables it), so removed tables regenerate only by re-running the query.

Exported run guide: every successful run also writes _UserGuide_please_read_me.html into the run folder — a self-contained explanation of every output file, every table column, and any warnings recorded for the run. Format (html / txt / markdown / disabled) is set in Settings → Default Settings → Run Guide Format.
