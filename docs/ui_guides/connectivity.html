Connectivity

The Connectivity tab holds the two connection-based similarity workflows, switched with the buttons at the top of the panel:

  • Find Similar — search for neurons similar to a query by connectivity profile (synaptic partner structure). Works across datasets (homolog search) or within one dataset (Target = Source). Find Similar guide
  • Comparison — compare the connectivity profiles of already-identified neurons (2+ queries) within one dataset or across several datasets at once. Comparison guide
Cross-dataset vs intra-dataset: connectivity comparison supports multiple datasets — the same query is profiled in every selected dataset and compared on the intra- and inter-dataset level. Morphological comparison (the Morphology tab) is intra-dataset only.

Output

Both sub-tabs save each run in its own timestamped folder under the selected output directory and write the exported run guide (_UserGuide_please_read_me.html) next to the results. See the per-sub-tab guides for the exact file trees.
