Shared references

Input File Formats explains neuron CSV/TSV/Excel files, path files and skeleton neuron layers. It is linked directly from every upload menu.

Pathfinding Algorithms explains how Find All Paths and Cross-Dataset Comparison are bounded: the built-in StrongestFirst enumeration (Max Paths budget with a reported tau) and the Edge Budget floor, plus the complete enumerators kept for scripts.

Quick tips

  • Neuron lists: type an entry and press Enter to make a chip, paste a comma/newline list, or upload a CSV/TSV/Excel file (first column). Numeric bodyIds are kept as integers.
  • Output folders: every run creates its own timestamped folder named {tool}_{dataset}_{detail}_{timestamp}, e.g. find-paths-complete_MCNS_aMe12_to_PPL101_L1w3_20260815_142520. The results panel always opens exactly that run's folder.
  • Long runs: the execution log streams live; output files appear when the run finishes.
  • First use of a dataset: the neuron table is downloaded once, so the first query is slower; later runs use the local cache.
