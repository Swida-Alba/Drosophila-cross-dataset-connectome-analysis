Co-Labeling Analysis

Analyze overlap between driver lines: which neuron types each line labels, Jaccard / weighted-Jaccard co-labeling matrices, and line specificity.

Quick start

  1. Enter at least two Driver Line Names as chips (e.g. VT037867, then R10A06, Enter after each).
  2. Keep Jaccard and Weighted Jaccard enabled.
  3. Click Run Co-Labeling.

Line specificity is high when a line labels few distinct types - useful for identifying selective drivers.

Output detail

Full (default) keeps every exported file. Compact drops the row-level source data (line_labeled_neurons/ and distribution_data_by_neuron.csv) once the similarity matrices and report are written — every removal is audited in the run's cleanup_audit.json. Matrices, expression data, by-type distributions, and the HTML report always stay. The NeuronBridge match cache is off by default (Settings → NeuronBridge Match Cache re-enables it), so removed tables regenerate only by re-running the analysis.

Exported run guide: every successful run also writes _UserGuide_please_read_me.html into the run folder — a self-contained explanation of every output file, every table column, and any warnings recorded for the run. Format (html / txt / markdown / disabled) is set in Settings → Default Settings → Run Guide Format.
