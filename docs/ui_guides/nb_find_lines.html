Find Driver Lines

Find GAL4 / Split-GAL4 driver lines whose expression matches EM neurons, using NeuronBridge color-depth search (CDS) or point-pattern matching (PPPM).

Quick start

  1. Enter EM neurons (bodyIds, types, instances, or patterns) — the box auto-suggests type/instance/bodyId names with the dataset they come from, and the history list tags each value with its datasets. Picking a suggestion adds the chip and keeps that query's rows listed (in either list a name already added stays, tinted and ticked, and clicking it again takes the chip back out), so several entries go in without retyping.
  2. Pick one or more Datasets, or keep the exclusive (all) indicator to search everywhere. Datasets NeuronBridge does not host are greyed out (advisory — runs still proceed with a warning).
  3. Keep Expand query names across datasets on to find every hosted release's equivalent of each name.
  4. Click Find Driver Lines.

Datasets & NeuronBridge coverage

NeuronBridge hosts EM bodies for a subset of DROCAT's datasets, and only at specific releases. The tab keeps an auto-refreshing coverage snapshot (cache/neuronbridge/coverage_snapshot.json) and shows it in the caption under the dataset selector:

  • Hosted exactly — searched as-is (e.g. hemibrain:v1.2.1, male-cns:v0.9, manc:v1.2.1, flywire FAFB v783).
  • Aligned — the same bodies live in another hosted release (e.g. male-cns:v1.0 → male-cns:v0.9, manc:v1.2.3 → manc:v1.2.1); expansion searches the hosted release's names.
  • Not hosted (disabled) — datasets with no NeuronBridge records (e.g. BANC, optic-lobe, fib19, mushroombody) are greyed out; runs targeting them warn but never block, in case a snapshot is stale or the refresh failed.

Image download options

  • Download Images from NeuronBridge and/or From FlyLight. FlyLight misses automatically fall back to NeuronBridge.
  • Image Formats: png/jpg (NeuronBridge); h5j/mp4/json added for FlyLight.
  • Image Types: cdm/mip, aligned, translation, metadata.
  • Max Images / Line: download cap per line.
  • FlyLight Collections: searched in priority order; missing lines automatically fall back to MCFO, RawImages, then NeuronBridge.
  • Simple Mode (labeled "Simple Mode (fewer files)"): fewer representative files.
  • Organize by Region: Brain/VNC subfolders; Flat Folder Structure saves files directly instead.
  • PDF Summary (on), PPTX Summary (off), Summary Background (black / white), and the PDF Images Per Page (cols 3 / rows 2) layout.
  • The Output Directory control (it inherits your saved default otherwise) sits above the run button.

Output

With expansion on (default), everything lands in ONE per-run folder:

{output_dir}/NB-find-lines-expanded_ALL_DNp01_20260915_040155/
  expansion_map.csv          # chip → expanded name → hosted release → mapping status
  expansion_summary.json     # original selection + coverage routing + cleanup audit
  user_warning_notes.txt     # (when unavailable datasets were targeted; "coverage:" prefix)
  cleanup_audit.json         # (Compact runs: removed files + reclaimed bytes)
  DNp01_lines.csv            # single-chip runs are FLAT (multi-chip: chip_{query}/ folders)
  line_summary.csv           # summary per line (sorted by weighted_score)
  gal4_lexa_summary.csv      # (when Split-GAL4 separation is on)
  split_gal4_summary.csv     # (when Split-GAL4 separation is on)
  parameters.json
  images/...                 # (when image download is on)
  {query}_summary.pdf        # (when a PDF/PPTX summary is requested)

With Expand query names off, the plain single-folder layout is used: NB-find-lines_MCNS_aMe12_20260815_145107/ with the same per-query files directly inside.

Output detail: Full (default) keeps every file. Compact keeps the newest N runs' match tables ({query}_lines.csv; N defaults to 1 — the latest query stays inspectable), prunes older Compact runs' tables, and removes the downloaded images once the PDF/PPTX is generated — every removal is audited in the runs' cleanup_audit.json, and a zero-byte summary/PDF (a crashed writer) never licenses deletion. The NeuronBridge match cache is off by default (Settings → NeuronBridge Match Cache re-enables it), so a pruned match table regenerates only by re-running the query.
Weighted score = avg match score × coverage. A line labeling all queried neurons ranks higher than one with a single high score.
Exported run guide: every successful run also writes _UserGuide_please_read_me.html into the run folder — a self-contained explanation of every output file, every table column, and any warnings recorded for the run. Format (html / txt / markdown / disabled) is set in Settings → Default Settings → Run Guide Format.
